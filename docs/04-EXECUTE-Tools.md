# Layer 4 — EXECUTE：Agent Execution（用真實工具完成任務）

> 不是想像，是實際整合。
> 效果目標：從概念到產出，以秒計。

---

## 為什麼需要這一層

前三層把「要做什麼」講清楚了，第四層要回答「**真的做出來**」。

差別在於：
- 「請 AI 描述一個部署流程」 vs.「請 AI 實際跑完部署並回報結果」
- 「請 AI 說明報表長怎樣」 vs.「請 AI 產生 .xlsx 檔並存到指定位置」

EXECUTE 強調**掛上真實工具**：CLI、API、MCP、瀏覽器、腳本。
沒有工具的 AI 只能給建議；掛上工具的 AI 才能交付。

---

## 核心觀念

1. **VAC 是輸入，OUTPUT 是合約**：執行者照 `⑤ STEPS` 走，交出 `⑦ OUTPUT` 指定的東西。
2. **工具要真**：能讀檔、寫檔、呼叫 API、跑指令，而不是「假設我可以」。
3. **可觀測**：每一步留下痕跡（log、中間檔、指令輸出），讓 VERIFY 有證據可查。
4. **失敗要能回退**：STEP 卡住時，走 VAC 裡寫好的 fallback，而不是硬掰。

---

## 執行者可掛的工具

| 類型 | 例子 | 典型用途 |
|------|------|----------|
| CLI / 腳本 | `git`, `python`, `ffmpeg`, 專案自訂指令 | 建置、轉檔、批次處理 |
| REST API / webhook | CMS、試算表、通知、內部服務 | 讀寫業務資料、觸發下游 |
| MCP servers | 檔案系統、資料庫、搜尋、雲端硬碟 | 讓模型有結構化的能力邊界 |
| 瀏覽器自動化 | 擷取、填表、截圖、回歸比對 | 需要真的開網頁才能完成的事 |
| 自訂整合 | 公司內部系統的 adapter | 沒有現成連接器時 |

> 安全邊界：憑證、金鑰、個資**不進 prompt、不進 URL**。工具呼叫要有最小權限。

---

## 具體做法

1. **備妥 INPUT**：VAC `② INPUT` 列的資料，全部到位（本地或執行時提供）。

2. **確認工具可用**：`⑥ TOOLS` 列的 CLI / API / MCP 都能連、有權限。

3. **照 STEPS 執行**：一步一步走，遇到決策點依 if/else 分支。

4. **每步留證據**：
   - 指令 → 存 stdout/stderr
   - 產檔 → 存中間檔
   - API → 存 request/response 摘要（去敏感資訊）

5. **產出 OUTPUT**：格式、結構、命名、存放位置完全照 `⑦ OUTPUT`。

6. **失敗處理**：STEP 失敗 → 走 VAC 的 fallback；沒有 fallback → 停下來回報，不要自行發明。

7. **交棒**：把 OUTPUT + 執行證據一起交給 VERIFY。

---

## 產出物

| 項目 | 說明 |
|------|------|
| 交付物 | 完全符合 `⑦ OUTPUT` 規格的檔案 / 結果 |
| 執行證據包 | 指令輸出、中間檔、API 摘要、截圖 |
| 執行記錄 | 用了哪個模型層級、耗時、是否走過 fallback |

---

## 反模式 Anti-patterns

- ❌ **假執行**：模型說「我已經幫你部署好了」，其實沒有任何工具被呼叫。
- ❌ **不留證據**：做完沒有 log、沒有中間檔 → VERIFY 無從查起。
- ❌ **偏離 OUTPUT 規格**：交了對的內容、錯的格式 / 位置 / 命名。
- ❌ **卡住就硬掰**：STEP 失敗卻編一個看起來完成的結果。
- ❌ **把金鑰塞進 prompt 或 URL**。
- ❌ **權限開太大**：給執行工具遠超任務所需的存取範圍。

---

## 檢查清單

- [ ] `② INPUT` 全部到位
- [ ] `⑥ TOOLS` 列的工具都能連、權限足夠且最小化
- [ ] 依 `⑤ STEPS` 逐步執行，決策點有照分支走
- [ ] 每一步都留下可查的證據
- [ ] 交付物格式 / 結構 / 命名 / 位置完全符合 `⑦ OUTPUT`
- [ ] 失敗時走 fallback 或明確停下回報，未自行編造結果
- [ ] 沒有任何憑證 / 個資出現在 prompt 或 URL
- [ ] OUTPUT 與證據包一起交給 VERIFY

---

## 範例

**VAC**：`VAC-045-v1.0-short-video-60sec` — 產出一份含時間戳的短影音腳本 markdown。

- INPUT：受眾設定、語氣、平台、3 款模板 → 到位。
- TOOLS：Haiku 生成腳本；小腳本做字數 ÷ 2.5 的秒數換算。
- STEPS：寫 hook → 寫說明 → 寫 CTA；每段算字數，超標就砍。
- OUTPUT：`VAC-045-v1.0-short-video-60sec-output.md`，存 `知識庫/Short Video/Scripts/`。
- 證據：字數換算表（每段字數 / 秒數）、超標時的刪修記錄。
- Fallback：若總長算出來 > 60 秒且無法再砍 → 停下，回報需要放寬 RULES。
