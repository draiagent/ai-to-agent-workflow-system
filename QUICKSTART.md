## 🎯 Step 2: Fill in the 8 Required Elements (3 minutes)

Open your copied template and fill:

### **① GOAL** (What's the final state?)
```
Example: "Design 3 new pet-friendly menu items that increase 
vegetarian customer satisfaction by 20%"
```

### **② INPUT** (What data do you need?)
```
Example: "Customer feedback (50+ surveys), current menu, 
vendor price list, nutritional database"
```

### **③ ASSETS** (What resources exist?)
```
Example: "Nutrition expert, test kitchen, customer database"
```

### **④ RULES** (What are the constraints?)
```
Example: "Must cost <¥X per serving, pass food safety, 
ready in 2 weeks"
```

### **⑤ STEPS** (How to execute?)
```
1. Analyze customer preferences (Week 1)
2. Create draft recipes (Week 1-2)
3. Test cook & adjust (Week 3)
4. Final approval (Week 4)
```

### **⑥ TOOLS** (What AI/tools to use?)
```
Example: "Claude Opus for ideation, 
Spreadsheet for cost tracking, 
Nutritionist for validation"
```

### **⑦ OUTPUT** (What's the deliverable?)
```
Example: "3 complete menu specs with recipes, 
nutritional analysis, cost breakdown"
```

### **⑧ ACCEPTANCE** (How to verify done?)
```
✓ Team approves taste test
✓ Nutritionist certifies healthy
✓ Cost meets budget (±10%)
✓ Food safety passes
```

## ✅ Step 3: Validate Your VAC (1 minute)

Before executing, check:

- [ ] GOAL is specific (no vague language)
- [ ] INPUT is available right now
- [ ] ASSETS are real and accessible
- [ ] RULES are clear constraints
- [ ] STEPS have timeline
- [ ] TOOLS are specified
- [ ] OUTPUT format defined
- [ ] ACCEPTANCE has objective criteria

**If any item is missing → Go back and fill it in**

## 🔍 Step 5: Verify the Result (Varies)

Run through 5-layer validation:

### Layer 1: Logic
```
✓ Does it make sense?
✓ Are there contradictions?
✓ Is reasoning sound?
```

### Layer 2: Flow
```
✓ All steps completed?
✓ No missing parts?
✓ Sequence correct?
```

### Layer 3: Visual/Design
```
✓ Looks right?
✓ Format matches spec?
✓ Professional quality?
```

### Layer 4: Data
```
✓ Numbers correct?
✓ Math checks out?
✓ Sources valid?
```

### Layer 5: Business
```
✓ Meets GOAL?
✓ Achieves success criteria?
✓ Stakeholders approve?
```

**If anything fails → Request revision**

---

## 👀 Step 6: Review (10 minutes)

Ask these 6 questions:

| Perspective | Question |
|-------------|----------|
| **Scope** | Did we change exactly what we planned? |
| **Complexity** | Is this simpler than it needs to be? Too complex? |
| **Security** | Are there any risks or vulnerabilities? |
| **Edge Cases** | What could break? What if conditions change? |
| **Consistency** | Does this match existing patterns/style? |
| **Regressions** | Could this break something else? |

**If issues found → Request changes**

## ❓ Common First-Time Mistakes

### ❌ VAC Too Vague
```
Bad:  "Do a presentation"
Good: "Create 10-slide product launch deck 
       in StepClear style with case studies,
       for CFO audience, by [date]"
```

### ❌ ACCEPTANCE Not Objective
```
Bad:  "Should look good"
Good: "✓ All 10 slides complete
       ✓ Design matches brand guidelines  
       ✓ CFO approves before presentation"
```

### ❌ Skipping VERIFY
```
Bad:  "AI said it's done, so it's done"
Good: "Check: logic, flow, design, data, KPIs"
```

### ❌ Not Storing the Result
```
Bad:  "Great, onto the next task"
Good: "Store VAC, create Skill, 
       plan Agent automation for next time"
```
